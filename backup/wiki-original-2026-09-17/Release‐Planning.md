# 릴리즈 플래닝

> 북적북적은 책만 판매하는 도서 큐레이션 커머스다. 책을 발견하고 구매하는 흐름과 추천 이유가 있는 대화형 AI 도서 추천을 V1, 개인화·취향 기억·알림·리뷰·마이페이지·사진으로 책 찾기 등 재방문 기능을 V2로 분류한다. V3는 신규 기능을 구현하지 않는다. V1·V2 지연 흡수 버퍼 + 성능 개선 · 버그픽스 · 프론트 디자인 고도화 기간이다. 단계별 데드라인은 로드맵의 기간과 맞춘다.

| 백로그 번호 | 유저스토리 요약 | 데드라인 |
| --- | --- | --- |
| 1 (V1) | 인증·온보딩: 사용자는 카카오 소셜 로그인과 로그아웃을 이용한다. 신규 회원은 온보딩에서 개인정보 동의(필수)를 마친 뒤 독서 시간대·책 선택 기준·선호 작가·카테고리·선호 도서를 입력하거나 건너뛰고 메인 화면으로 이동한다. 인증이 필요한 기능에 접근하면 로그인 후 원래 목적지로 돌아간다. | 2026년 9월 18일 |
| 2·3 (V1) | 책 탐색: 사용자는 홈에서 최근 24시간 판매·조회 데이터를 기준으로 매시간 갱신되는 책 랭킹과 취향 기반 추천 섹션을 확인한다. RAG 기반 검색(LLM 미사용)에서 필터·정렬(인기·최신·가격)·3열 결과 그리드·무한 스크롤을 이용하고, 도서 상세에서 기본 정보·책 소개·맞춤 정보와 판매가·할인·품절 등 구매 정보를 확인한다. 도서 클릭·상세 이동·찜 흐름을 이용한다. | 2026년 9월 25일 |
| 2 (V1) | 대화형 AI 도서 추천: 사용자는 상황·기분을 최대 200자로 입력하거나 예시 문구를 선택해 추천 도서 3~4권을 카드로 받고 추천 이유를 확인한다. 후속 입력으로 조건을 좁히는 멀티턴 대화를 지원하고, 결과 없음·30초 초과·API 오류에는 재질문·재시도를 제공한다. 대화 이력은 화면을 벗어나면 유지하지 않는다(도서 상세 왕복 제외). | 2026년 10월 2일 |
| 4 (V1) | 장바구니·주문·결제: 사용자는 장바구니에서 상품을 선택·삭제하고 수량을 1~99개로 조정한다. 주문 과정에서 배송지를 입력하고 20,000원 이상 무료 배송·미만 3,000원 배송비를 적용한 주문을 확인한 뒤 PG 샌드박스 테스트 결제를 진행한다. 결제 실패·취소 시 입력값을 유지하고 결제 완료 화면에서 주문 요약과 다음 동선 안내를 확인한다. | 2026년 10월 2일 |
| 1~5 (V1) | V1 출시 검증: 추천·도서 클릭률, 구매 전환율, 평균 주문 금액을 기록할 수 있는지 확인한다. 검색·품절·결제 실패와 인증 복귀를 포함한 통합·부하 테스트를 수행한다. 알림, 마이페이지, 리뷰, 사진으로 책 찾기는 V1에서 제외하고 1차 배포 후 MVP를 시연한다. | 2026년 10월 2일 |
| 5 (V2) | 개인화·취향 기억: 사용자는 온보딩 정보와 검색·조회·구매·평점 기록을 반영한 개인화 추천을 받는다. AI 추천 대화에서 파악된 취향은 기억 목록으로 누적되고, 취향 정보 수정에서 항목별 확인·삭제·실행 취소와 전체 삭제를 제공한다. 삭제한 기억은 이후 추천에 사용하지 않는다. | 2026년 10월 9일 |
| 3·4·7 (V2) | 알림·회원 활동: 알림에서 재입고·가격 인하·주문 상태·관심 작가의 신간 알림을 읽음·안 읽음으로 관리한다. 마이페이지와 프로필 설정에서 프로필·로그아웃·회원탈퇴를 이용하고 배송지 관리와 주문 내역에서 배송지와 주문 상태를 관리한다. | 2026년 10월 16일 |
| 6·8 (V2) | 리뷰·사진으로 책 찾기: 구매 이력이 있는 회원만 1-5점 평점과 10-1,000자 리뷰를 작성한다. 스포일러 표시, 최신순·평점순 정렬, 공감·신고·수정·삭제를 제공한다. 사용자는 AI 추천 대화에 책 사진을 첨부해 VLM으로 책을 인식하고, 찾은 책과 구매한 책을 나의 도서관에서 관리한다. | 2026년 10월 23일 |
| 1~8 (V2) | V2 출시 검증: 추천 클릭률과 추천 경유 구매 전환율, 재방문율, 나의 도서관 저장 수를 V1 기준선과 비교한다. 삭제한 취향 기억이 이후 추천에 사용되지 않는지 확인하고, 개인화·알림·리뷰·마이페이지가 V1의 인증·추천·구매 흐름과 연결되는지 검증한다. 통합·부하 테스트와 회고를 마친 뒤 2차 배포한다. 이메일·전화번호 가입과 비밀번호 찾기는 별도 검토 범위로 관리한다. | 2026년 10월 23일 |
| 1~8 (V3) | V1·V2 지연 흡수와 안정화: V3에 신규 기능을 두지 않으므로 이 기간을 먼저 V1·V2의 밀린 작업을 마무리하는 버퍼로 사용한다. 남은 결함을 심각도로 분류해 처리하고, 인증·검색·추천·구매·개인화 전체 흐름의 통합·회귀 테스트를 수행한다. | 2026년 10월 30일 |
| — (V3) | AI 추론 성능 개선: 임베딩 자체 서빙 전환과 소형 LLM 파일럿을 실측으로 마무리한다. 추천 1턴 p95 지연, 검색 쿼리 임베딩 p95, 추천 이유 캐시 적중률, 월 추론 비용을 전환 전후로 비교해 개선 폭을 수치로 남긴다. 검색 품질은 recall@10 기준선 대비 −2%p 이내 유지를 전환 조건으로 한다. | 2026년 11월 6일 |
| — (V3) | 프론트엔드 디자인·사용성 고도화: 화면 완성도, 반응형 대응, 로딩·빈 상태·오류 화면, 인터랙션을 다듬는다. V1·V2 지표에서 이탈률이 높았던 화면을 우선순위로 삼고 개선 전후의 이탈·전환 변화를 확인한다. | 2026년 11월 13일 |
| — | 최종 검증·정리: 전체 기능의 통합·회귀·부하 테스트와 오류 수정을 진행하고 3차 배포와 최종 시연을 수행한다. 성능 개선 결과(전후 수치), 테스트 결과, 배포·운영 절차와 최종 프로젝트 문서를 마무리한다. | 2026년 11월 17일 |
