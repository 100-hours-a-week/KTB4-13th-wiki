# 프로덕트 백로그

> 북적북적은 책만 판매하는 도서 큐레이션 커머스다. 책을 발견하고 구매하는 기본 흐름과 설명 가능한 대화형 AI 도서 추천은 V1, 개인화·취향 기억·알림·리뷰·마이페이지·사진으로 책 찾기 등 재방문 기능은 V2로 분류한다. v3는 신규 기능을 구현하지 않는다. V1·V2 지연 흡수 버퍼 + 성능 개선 · 버그픽스 · 프론트 디자인 고도화 기간이다.
>
> 제품 검증은 추천 클릭률, 추천 경유 구매 전환율, 평균 주문 금액, 재방문율, 나의 도서관 저장 수를 기준으로 진행한다.

<aside>
💡 사용자는 회원가입과 로그인을 통해 자신의 계정을 생성하고 관리할 수 있다.
</aside>

### 프로덕트 백로그 세부사항

|   |
| --- |
| V1 · 사용자는 카카오 소셜 계정으로 로그인하고, 최초 로그인 시 서비스 계정을 생성할 수 있다. |
| V1 · 사용자는 로그인한 계정으로 로그아웃할 수 있다. |
| V1 · 로그인하지 않은 사용자가 주문 등 인증이 필요한 기능에 접근하면 로그인 화면으로 이동한다. |
| V1 · 로그인 전 사용자가 있던 화면과 목적지를 보존하고, 인증이 끝나면 원래 화면으로 돌아간다. |
| V1 · 신규 회원은 로그인 후 온보딩을 한 번 진행하고 메인 화면으로 이동한다. |
| V2 검토 · 사용자는 이메일 또는 전화번호로 회원가입·로그인을 할 수 있다. |
| V2 검토 · 사용자는 비밀번호를 잊었을 때 비밀번호 찾기를 이용할 수 있다. |
| V2 · 사용자는 마이페이지의 프로필 관리에서 자신의 프로필 정보를 조회하고 수정할 수 있다. |
| V2 · 사용자는 더 이상 서비스를 이용하지 않을 때 회원탈퇴할 수 있다. |

## 프로덕트 백로그 2

<aside>
💡 사용자는 원하는 분위기나 상황을 입력하여 자신에게 적합한 도서를 추천받고 추천 이유를 확인할 수 있다.
</aside>

### 프로덕트 백로그 세부사항

|   |
| --- |
| V1 · 사용자는 메인에서 책 랭킹과 추천 섹션을 확인할 수 있다. |
| V1 · 메인의 책 랭킹은 최근 24시간 판매·조회 데이터를 기준으로 매시간 갱신한다. |
| V1 · 사용자는 온보딩에서 입력한 정보를 바탕으로 규칙 기반 도서 추천을 받을 수 있다. |
| V1 · 사용자는 검색에서 도서명을 입력하고, 검색어를 유지한 채 결과를 확인할 수 있다. |
| V1 · 사용자는 카테고리·가격·출간 연도 필터와 인기·최신·가격·평점 정렬을 사용할 수 있다. |
| V1 · 사용자는 검색 결과를 3열 그리드로 확인하고 무한 스크롤로 더 불러올 수 있다. |
| V1 · 사용자는 검색 결과에서 원하는 도서를 선택해 도서 상세로 이동할 수 있다. |
| V1 · 사용자는 도서 상세에서 도서의 표지·제목·저자·출판사·출간일·가격 등 기본 정보를 확인할 수 있다. |
| V1 · 책 카드의 클릭과 상세 이동을 기록해 어떤 추천·노출이 발견으로 이어지는지 확인할 수 있다. |
| V1 · 사용자는 AI 추천에서 원하는 상황이나 기분을 최대 200자로 입력하거나 예시 문구를 선택할 수 있다. |
| V1 · AI는 자연어 입력과 사용자의 취향 정보를 분석해 추천 도서 3~4권을 카드로 제시할 수 있다. |
| V1 · AI는 사용자의 입력과 책의 주제·정서가 연결되는 이유를 한 줄로 설명할 수 있다. |
| V1 · 사용자는 후속 입력으로 조건을 추가·수정하며 추천을 이어 갈 수 있다(멀티턴 대화). |
| V1 · 사용자는 추천 결과 카드에서 추천 이유를 확인하고 도서 상세로 이동할 수 있다(취향 매칭 점수 표시는 정의 확정 후 반영). |
| V1 · 추천 결과가 없거나 응답 시간이 30초를 초과하거나 API 오류가 발생하면 사용자는 다시 질문하거나 재시도할 수 있다. |
| V1 · AI 추천 대화 이력은 화면을 벗어나면 유지하지 않으며 서버에도 저장하지 않는다. 추천 카드에서 도서 상세로 갔다가 돌아오는 왕복은 화면 이탈로 보지 않는다. |

</aside>

### 프로덕트 백로그 세부사항

|   |
| --- |
| V1 · 사용자는 도서를 장바구니에 담을 수 있다. |
| V1 · 사용자는 장바구니에서 전체 또는 일부 상품을 선택하고 선택한 상품을 삭제할 수 있다. |

| V1 · 선택 상품 합계가 20,000원 이상이면 배송비를 무료로 계산하고, 20,000원 미만이면 3,000원을 계산한다. |
| V1 · 사용자는 주문 화면에서 배송지를 입력하고 주문 상품과 주문 정보를 확인할 수 있다. |
| V1 · 사용자는 PG 샌드박스 테스트 결제로 주문을 완료할 수 있다. |
| V1 · 결제에 실패하거나 취소하면 입력한 배송지와 주문 정보를 유지하고 오류를 안내한다. |
| V1 · 사용자는 결제 완료 화면에서 주문번호·상품·수량·총 결제 금액을 확인하고 다음 동선(계속 둘러보기 등)으로 이동할 수 있다. |
| V1 · 주문 데이터에서 평균 주문 금액과 재구매 여부를 확인할 수 있다. |
| V2 · 사용자는 배송지 관리에서 배송지를 추가·수정·삭제하고 기본 배송지를 관리할 수 있다. |
| V2 · 사용자는 주문 내역에서 완료된 주문을 포함한 주문 내역과 주문 상태를 확인할 수 있다. |

## 프로덕트 백로그 5

<aside>
💡 사용자는 자신의 취향을 설정하고 이용 기록을 기반으로 개인화된 도서를 추천받을 수 있다.
</aside>

### 프로덕트 백로그 세부사항

|   |
| --- |
| V1 · 개인정보 수집·이용 동의(필수)는 온보딩에서 받고, 동의 후에는 나머지 온보딩 단계를 건너뛸 수 있다. 동의 전문에는 AI 추천 대화에서 파악된 취향이 기억으로 저장·활용된다는 내용을 고지한다. |
| V1 · 사용자는 온보딩에서 독서 시간대와 책 선택 기준을 입력할 수 있다. |
| V1 · 사용자는 선호 작가와 대분류·세부 카테고리를 선택할 수 있다. |
| V1 · 사용자는 선호 도서를 5권 이상 선택해야 온보딩을 완료할 수 있다. |
| V1 · 사용자는 온보딩 정보를 활용한 메인의 규칙 기반 추천을 받을 수 있다. |
| V2 · 사용자는 기존에 입력한 취향 정보를 수정할 수 있다. |
| V2 · 사용자는 검색·조회·구매·평점 기록을 반영한 개인화 추천을 받을 수 있다. |
| V2 · 개인화 추천은 사용자의 취향뿐 아니라 책의 주제·정서와 이용 행동의 연결을 고려한다. |
| V2 · 사용자는 취향 관리에서 추천에 사용되는 취향 기억을 항목별로 확인할 수 있다. |
| V2 · 사용자는 취향 기억을 개별적으로 삭제하거나 되돌릴 수 있다. |
| V2 · 삭제한 취향 기억은 이후 메인 추천과 AI 추천 응답에 사용하지 않는다. |
| V2 · 추천 결과의 클릭·구매를 기록해 개인화 추천과 서비스 개선에 활용한다. |
| V2 · 추천 시스템은 온보딩 정보와 이용 행동을 구분해 저장하고 추천 입력으로 연결한다. |

💡 사용자는 책 사진을 찍어 책을 찾고, 찾은 책과 구매한 책을 나의 도서관에서 관리할 수 있다.
</aside>

### 프로덕트 백로그 세부사항

|   |
| --- |
| V1 · 사용자는 AI 추천 대화에서 카메라 촬영 또는 갤러리 이미지를 첨부해 책을 찾을 수 있다. |
| V2 · AI(VLM)는 이미지 속 책을 인식해 카탈로그의 해당 도서와 매칭하고 도서 상세로 연결한다. |
| V2 · 카메라·갤러리 권한이 없으면 권한 안내를 노출하고, 갤러리 선택 경로는 계속 제공한다. |
| V2 · 사용자는 인식된 책을 나의 도서관에 담고, 나의 도서관에서 사진으로 찾은 책과 구매한 책을 모아 볼 수 있다. |
| V2 · 나의 도서관에서 책을 단건 또는 여러 권 선택해 뺄 수 있으며, 주문·리뷰 데이터는 유지된다. |
