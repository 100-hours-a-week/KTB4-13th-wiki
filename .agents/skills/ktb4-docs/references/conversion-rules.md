# 변환 규칙 — 원본을 오염시키지 않는 법

## 대원칙

**원문을 줄이거나 다시 쓰지 않는다. 자리만 옮긴다.** 원본의 모든 문장·숫자·표 행은 변환본(본문 + 선택 근거 + 부록) 어딘가에 그대로 있어야 한다.

## 허용되는 변경

| 변경 | 예 |
|---|---|
| 섹션·문단 위치 이동 | 선택 이유 문단을 `rationale.md` 로 |
| 제목 레벨·번호 조정 | `# 3-5. …` → `## 5. …` |
| 긴 예시·표·코드를 부록으로 | JSON 예시 → `appendix.md` |
| 상태 헤더·요약 줄·짝 문서 링크 추가 | frontmatter, `**요약**` |
| 링크 주소를 docs 상대 경로로 | 원본 위키 URL → `../3-cd-pipeline/design.md` |
| 요약 문장 **추가** | 원문은 그대로 두고 앞에 한 줄 추가 |
| 결정 로그에 한 줄 **추가** | 원문은 그대로 |
| 긴 섹션을 `<details>`로 접기 | 원문 그대로, **보이는 방식만** 바꾼다. 원본에 이미 `<details>`가 있었으면 그대로 유지(펼쳐서 평문화하지 않는다) |
| 다이어그램 노드의 긴 설명을 노드 밖 표로 이동 | 노드 텍스트는 짧게, 원문 문장은 다이어그램 바로 아래 표에 그대로 (style-guide.md #7). 텍스트 자체는 지우지 않고 위치만 바꾸는 것이라 대원칙 위반 아님 |

## 금지

| 금지 | 이유 |
|---|---|
| 문장 요약·축약 | 조건이 빠진다 ("신김치면 설탕") |
| 문장을 표·목록으로 재작성 | 부정어·"만"이 빠지거나 뒤집힌다 |
| 표 셀 내용 줄이기 | 예외 조건이 사라진다 |
| 문체 변경 ("~합니다" → "~한다") | 권고/규칙 뉘앙스가 바뀐다 |
| 영어 ↔ 한국어 용어 변경 | 검색·대조가 어려워진다 |
| 충돌하는 원문 중 한쪽 삭제 | 판단 근거가 사라진다 |
| 원본에 없는 사실 추가 | 원본 오염 |
| `backup/` 파일 편집 | 원본 오염 |

가독성을 위해 표·목록이 꼭 필요하면 **원문 문장을 지우지 말고** 표를 요약으로 추가하고, 원문은 바로 아래나 부록에 둔다.

## 뜻이 뒤집히기 쉬운 곳 (반드시 원문과 한 줄씩 대조)

| 종류 | 단어 | 원본 예 |
|---|---|---|
| 부정 | 않, 없, 아니, 금지, 불가 | 자동 Rollback에는 별도 승인이 필요하지 **않으며** |
| 한정 | 만, 뿐, 단 | 수동 Rollback할 때**만** 재승인 |
| 주체 | 다른, 같은, 담당 | 준비한 사람과 **다른** 담당자 1명 |
| 범위 | 최대, 최소, 이내, 이상, 이하, 초과, 미만 | 최대 5분 이내 |
| 순서·중단 | 먼저, 이후, 실패하면, 변경하지 않 | AI 검증 실패 시 App EC2는 변경하지 않음 |
| 버전 | (V2), V3 | 이미지 턴 (V2) |
| 예외 예시 | 0건, degraded, 오류 응답 | 부록으로 옮겨도 삭제 금지 |

## 절차

**중간 승인 없이 끝까지 진행하고 결과를 한 번에 보고한다** (2026-09-17 결정 — 이유는 `decisions.md` 참고). 아래 1번의 옮김표는 만들기만 하고, 승인을 기다리지 않고 2번으로 바로 넘어간다. 유일하게 멈추는 경우는 3번의 "기준이 없을 때"뿐이다 — 그건 판단이라 대신 정하지 않는다.

1. **옮김표 작성**
   ```markdown
   | 원본 파일 | 원본 섹션 | → 새 파일 | 새 섹션 |
   |---|---|---|---|
   | 3단계…설계.md | 1. CD 적용 범위 > 배포 대상 | design.md | 1. 범위와 전제 |
   | 3단계…설계.md | 3. 다른 전략을 제외한 이유 | rationale.md | 1. 배포 전략 |
   | 3-5-….md | 4. CD 증분 비용 검토 | appendix.md | 비용 |
   ```
   원본 섹션이 하나라도 빠지면 안 된다.
2. **새 파일에 원문 복사** 후 허용된 변경만 적용.
3. **충돌 처리**: `decisions.md` 에 기준이 있으면 본문은 기준값 원문, 다른 원문은 `appendix.md` 의 `## 원본 차이` 에 출처와 함께 그대로 옮긴다.
   ```markdown
   ## 원본 차이
   > 출처: 3-5 최소 구조 비용 및 현재 한계 · 기준: 3단계 상위 페이지 (결정 로그 09-17)

   (원문 그대로)
   ```
   **기준이 없으면 여기서만 멈추고 묻는다.**
4. **검사**: `preserve_check.py` → 오류 0. `check_docs.py` → 오류 0.
5. `page-map.md` 상태 갱신, PR 생성.
6. **결과 보고**: 옮김표, 검사 결과, `문장 변경` 목록(원본 / 변환본 두 칸 표)을 PR과 함께 한 번에 보여준다. 문제가 있으면 사용자가 그때 다시 요청한다.

## 부록으로 옮기는 기준

| 옮기는 것 | 본문에 남기는 것 |
|---|---|
| 요청·응답 JSON, YAML, 명령어 예시 | 필드 표, 규칙 문장 |
| 비용 계산 상세, 가격 근거 | 결론 한 줄 + 부록 링크 |
| 제외한 대안의 긴 설명 | (선택 근거 문서로) |
| 원본 차이 | - |

부록에 옮긴 뒤 본문 원래 자리에 `상세: [부록 - 비용](appendix.md#비용)` 한 줄을 남긴다.

## 승인된 원본 변경

기준값 적용 외에 원문 변경이 꼭 필요하면 `docs/_preserve-overrides.tsv` 에 한 줄 기록하고 PR에서 파트 승인을 받는다.

```text
group	원문에 포함된 문구	사유
cld-3	예시 문구	결정 로그 09-17
```
